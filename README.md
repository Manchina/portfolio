# Prem Manchina &middot; 3D Interactive Portfolio

> **High-Performance 3D Developer Portfolio & System Architecture Showcase**  
> Built with React 19, TypeScript, Three.js WebGL, Tailwind CSS, and Web Audio API.

---

## ⚡ Live Features

- **⚛️ 3D Quantum Reactor Hero (WebGL)**: Interactive Three.js particle vortex with multi-layered glowing core, 3 orbital rings, mouse parallax, and click shockwave pulses.
- **⚡ AWS Event Architecture Visualizer**: Interactive blueprint of the Wysbryx Technologies Enterprise Notification Engine (`Fastify v5 → SNS → SQS/DLQ → Lambda → SES + Aurora PostgreSQL`).
- **💻 Cyber Terminal (HUD Mode)**: Interactive Unix-style terminal CLI with custom commands (`help`, `about`, `projects`, `skills`, `experience`, `certifications`, `metrics`, `contact`, `matrix`, `sudo hire prem`).
- **🎴 3D Perspective Tilt Project Cards**: Curated flagship repositories with mouse glare reflection, technical metrics, and architectural deep-dive modals.
- **🎯 Technical Radar & Skills Matrix**: Filterable skill clouds across Backend & Distributed Systems, Cloud & DevOps, Databases & AI, and Frontend Engineering.
- **💼 Work Experience Timeline**: Detailed engineering deliverables and metrics for Wysbryx Technologies (Product Engineer & Full Stack Intern).
- **📜 Verified Credentials**: Google Cloud Certified Associate Cloud Engineer & Microsoft Certified Azure AI Fundamentals.
- **📄 Executive Resume Viewer**: Clean modal preview with 1-click printable PDF view and text copy.
- **🔊 Web Audio API Synthesizer**: Zero-dependency tactile sound feedback with persistent mute toggle.
- **📡 Direct Contact Uplink**: Interactive message terminal with confetti feedback, copy email/phone triggers, and direct links to GitHub, LinkedIn, and LeetCode.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite 8
- **3D Graphics**: Three.js (WebGL Canvas)
- **Styling**: Tailwind CSS v4 + Glassmorphism & Cyber Glow utilities
- **Icons**: Lucide React + Custom SVG Social Icons
- **Effects**: Web Audio API Sound Synthesizer + Canvas Confetti
- **Typography**: Space Grotesk, Syne, JetBrains Mono, Plus Jakarta Sans

## 🚀 Quick Start

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/Manchina/portfolio.git
cd portfolio
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized static build will be generated in `dist/`.
